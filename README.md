## ▶️ How to Run

**Prerequisites:** Java 8+ (JDK) installed on your system.

```bash
# Clone the repository
git clone https://github.com/Saisrikar20/JAVA.git
cd JAVA

# Navigate to a problem directory
cd hackerrank/medium/<problem-name>

# Compile and run
javac Solution.java
java Solution
```
